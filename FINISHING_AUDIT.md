# Finishing-Pass Gameplay Audit

## Protected creative boundary

The existing fox heroes, small enemy roster, bosses, and their source assets remain protected. The finishing pass will not replace, reskin, delete, or alter any of them. Supporting gameplay additions may use existing enemy types, procedural arcade effects, non-character city objects, banners, and pickups.

## Current strengths

The game already has an effective base loop: left-to-right lane movement, four themed recurring pressures, three fronts per level, destructible props, health and Super pickups, and boss-specific projectile patterns. The three-tier Super system provides visible escalation from grenade to bazooka to air strike. The current visual direction is an urban 16-bit side-scrolling arcade setting with a shallow, grounded battle lane.

## Main opportunity

Each front currently follows the same cadence: a fixed group of enemies appears, props sit in fixed positions, the group is defeated, and the next front opens. The enemy types have different attacks, but the encounter logic does not yet create enough short, high-pressure changes in tempo. This is the main source of repetition—not the existing characters.

## Finishing-pass focus

| Area | Existing limitation | Finishing addition |
| --- | --- | --- |
| Racing-thought pressure | Groups are static after spawning. | Use short **Thought Surge** reinforcement waves built from the existing enemy types, with a clear arcade warning and bonus reward for clearing them. |
| Player payoff | Kills mostly award score. | Add a decaying **Resolve** streak that rewards steady clears with a temporary Focus state, score bonuses, and a power-bank opportunity. |
| Props | Props are useful but predictable. | Add clearly signposted **Resilience Cache** moments using the existing crate/barrel objects, guaranteeing a support pickup after a notable clear. |
| Stage tempo | All three fronts have similar pacing. | Vary fronts into Rush, Hold the Line, and Breakthrough moments, using existing characters and the current shallow lane system. |
| Boss anticipation | Bosses appear immediately after the final front. | Add a brief warning build-up and a themed final surge from the existing enemy roster before the boss entry. |
| Theme | Enemy names carry the message, but pressure rhythm is understated. | Use concise arcade banners such as **RACING THOUGHTS**, **HOLD YOUR GROUND**, **BREATHE — BREAK THROUGH**, and **YOU ARE NOT ALONE**. |

The goal is to make the player constantly react, choose whether to break props or push forward, chase short rewards, and feel the pressure rise and release. No new story direction or character replacement is required.
