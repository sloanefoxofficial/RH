# Sloane Fox — Original Arcade Event Rebuild: Review Proof

This package contains the gameplay rebuild based on high-level study of classic arcade lane-brawler pacing. It uses **original Sloane Fox events, scenery, and interactions**; it does not copy another game’s artwork, characters, stage layouts, or encounter sequences.

## Review routes

| Review URL suffix | What it holds on screen |
| --- | --- |
| `?demo&stage=0&arcade=normal` | Normal Level 1: tighter combat framing, textured city lane, props, traffic, mixed pressure wave, and nine-front route. |
| `?demo&stage=0&inspect=runner` | Support Runner: an optional moving aid target that drops a power bank or first-aid reward when hit. |
| `?demo&stage=0&inspect=case` | Pressure Case: an original breakable that can drop a bank or first aid. |
| `?demo&stage=1&inspect=board` | Community Board: an original resilience object that grants a short safety window plus a bank when opened. |

| `?demo&inspect=ready66` | Rocket Launcher-ready panel at 66 charge. |
