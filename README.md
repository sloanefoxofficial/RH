# Global Jump to top update

Replace `App.jsx` and `images.js` with the supplied files, then deploy the whole project.

A floating circular **Jump to top** button now appears on every app page after the user scrolls down. It uses the Resilience Hub green/teal gradient, sits above the existing Need Help Now control, has an accessible label and tooltip, scrolls smoothly when appropriate, and switches to instant scrolling when reduced motion is enabled.
